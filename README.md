# Китай без обмана — гайд и калькулятор

Офлайн-приложение для того, чтобы заказывать из Китая дёшево, проверенно и без платных курсов. Работает как обычный сайт: можно открыть `index.html` на телефоне или залить на GitHub Pages.

> **1687 — ошибка.** Правильный сайт — [1688.com](https://www.1688.com). Всегда проверяй адрес в браузере.

## Что внутри

- **Где дешевле:** сравнение 1688, Pinduoduo, Taobao, Alibaba.com, AliExpress, Ozon Global, Wildberries, Poizon/JD/Tmall.
- **Чек-лист:** продавец, посредник, товар, тестовый заказ. Галочки сохраняются в браузере.
- **Смета:** калькулятор полной стоимости — товар, выкуп, доставка по Китаю, карго, РФ, таможня, цена за штуку и сравнение с ценой в РФ. Есть готовые примеры «1 пара» и «10 пар».
- **Шаблоны:** сообщения продавцу на китайском и английском, запрос посреднику, претензия при браке. Кнопка копирования.
- **Отчёт:** форма по заказу, сохранение в браузере и скачивание `.txt`.
- **Таможня:** лимиты, красные флаги, ограничения на товары, бесплатные источники вместо курсов.
- **Ссылки:** все площадки и официальные справочные сайты.
- **PWA:** ставится на главный экран телефона и работает офлайн через service worker.
- **Тёмая/тёмная тема** и поиск по всем разделам.

## Быстрый старт

### Вариант 1. Просто открыть

Открой `index.html` в браузере. Ничего устанавливать не нужно, интернет не требуется.

### Вариант 2. GitHub Pages

1. Создай публичный репозиторий `china-order-guide`.
2. Загрузи сюда все файлы этого каталога.
3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Воркфлоу `.github/workflows/pages.yml` сам соберёт и опубликует сайт.

Ссылка будет вида:

```
https://<твой-логин>.github.io/china-order-guide/
```

### Вариант 3. Через git

Подробности — в [PUBLISH.md](PUBLISH.md). Коротко:

```sh
sh publish.sh <твой-github-логин>
```

Или вручную:

```sh
git init
git add .
git commit -m "Initial commit: Китай без обмана"
git branch -M main
git remote add origin https://github.com/<твой-логин>/china-order-guide.git
git push -u origin main
```

Если Git требует авторизацию — используй personal access token вместо пароля.

## Правила, которые стоит помнить

1. Первый заказ — тестовый, 500–1500 ₽, без бренда и без опта.
2. Никакой оплаты до согласованной сметы и проверки посредника.
3. Не занижай стоимость в декларации и не дроби партию на посылки.
4. Не покупай «курсы» и «доступ к базе поставщиков» — всё открыто.
5. Тарифы и таможенные правила меняются — проверяй на дату заказа.

## Дисклеймер

Информация носит справочный характер. Точные тарифы, курсы и правила ввоза уточняй на сайте площадки, у перевозчика и на [customs.gov.ru](https://customs.gov.ru).
