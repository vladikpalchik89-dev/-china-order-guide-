# Быстрый старт

## 1. Выбери схему

| Задача | Куда | Прямо в РФ |
|---|---|---|
| 1–2 вещи, просто | AliExpress / Ozon Global / Wildberries | Да |
| Реально дёшево, готов ждать | 1688 или Pinduoduo + посредник | Нет |
| Партия и поставщик | Alibaba.com | Да, может поставщик |

**1687 — не существует. Правильный сайт — 1688.com.**

## 2. Проверь перед оплатой

- Продавец: рейтинг, отзывы, реальные фото, артикул, вес, ответы на вопросы.
- Посредник: юрлицо, договор/оферта, склад в Китае, прозрачные тарифы, фотоотчёт, трекинг, кто отвечает за брак.
- Товар: артикул, размер, цвет, комплектность, нет подделки под бренд.
- Не плати на карту физлица и не занижай декларацию.

## 3. Посчитай смету

```
Товар = юани × курс
+ выкуп ~5%
+ доставка по Китаю
+ вес × тариф карго
+ доставка по РФ
+ таможня
= ИТОГО

Цена за штуку = ИТОГО / количество
Сравни с ценой в РФ.
```

Ориентир карго: до 3 кг — 850 ₽/кг, 3–5 кг — 723 ₽/кг, 5–10 кг — 553 ₽/кг.

## 4. Напиши по шаблону

Готовые тексты на китайском, английском и русском — в приложении, вкладка **Шаблоны**, и в файле `04_ШАБЛОНЫ_СООБЩЕНИЙ.txt`.

## 5. Фотоотчёт и получение

Требуй фото с номером заказа и датой, бирку крупно, вес на весах, упаковку. При получении сними видео вскрытия. Заполни отчёт во вкладке **Отчёт**.

## 6. Без курсов

Всё нужное уже здесь. Дополнительно — официальные сайты: customs.gov.ru, help.aliexpress.com, help.alibaba.com, правила 1688.
