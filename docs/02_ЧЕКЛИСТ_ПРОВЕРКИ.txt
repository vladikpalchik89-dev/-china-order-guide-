============================================================
А. ПРОВЕРКА ПЛОЩАДКИ И ПРОДАВЦА (1688 / Taobao / PDD)
============================================================
[ ] Ссылка ведёт на нужный домен: 1688.com, taobao.com, pinduoduo.com.
    Не на похожий «1687», не на ссылку из чата/СМС.
[ ] В браузере https и замок.
[ ] У продавца есть рейтинг/уровень, число сделок, отзывы.
[ ] Отзывы не все одинаковые и не с одним днём.
[ ] В отзывах есть реальные фото покупателей, а не только картинки магазина.
[ ] Продавец отвечает на вопросы (см. 04_ШАБЛОНЫ_СООБЩЕНИЙ).
[ ] Есть точный артикул, цвет, размер, вес, состав, комплект.
[ ] Продавец согласен отправить на склад посредника в Китае.
[ ] Нет требований «переведи на карту физлица», «оплата вне сайта».

Б. ПРОВЕРКА ПОСРЕДНИКА (КТО ВЫКУПАЕТ И ВЕЗЁТ)
============================================================
[ ] Это юрлицо / ИП с названием, ИНН, договором или публичной офертой.
[ ] Есть сайт, поддержка, телефон, адрес склада в Китае.
[ ] Тарифы выложены заранее: выкуп %, доставка по Китаю, карго за кг,
    хранение, последняя миля по РФ, страховка.
[ ] Есть фотоотчёт на складе с вашим номером заказа и датой.
[ ] Есть трекинг после отправки из Китая.
[ ] Прописано, кто предъявляет претензию продавцу при браке.
    Должен — посредник, потому что он покупал от своего имени.
[ ] Прописаны сроки: приём на складе, отправка, доставка в РФ.
[ ] Отвечает на вопросы до оплаты, а не «потом разберёмся».
[ ] НЕ просит «занизить стоимость в декларации» и «дробить посылки».
[ ] НЕ предлагает «гарантию 100%», «без таможни вообще», «обойдём закон».

КРАСНЫЕ ФЛАГИ — СРАЗУ ОТКАЗ:
- оплата на личную карту unknown человека;
- цена в разы ниже рынка и только «сегодня»;
- нет договора/оферты, нет адреса склада;
- просят скинуть скрин оплаты «для отчёта» и не дают подтверждения;
- отвечают только в мессенджере и пропадают при вопросе про документы.

В. ПРОВЕРКА САМОГО ТОВАРА
============================================================
[ ] Артикул совпадает с карточкой и с биркой на фотоотчёте.
[ ] Размер/цвет совпадают с заказом.
[ ] Вес совпадает с расчётом (взвешивание на складе).
[ ] Комплектность: что именно должно лежать в коробке.
[ ] Нет открытого брака на фото: пятна, швы, трещины, перекосы.
[ ] Нет подделки под бренд: логотипы «Adidas/Gore-Tex» по 49 юаней —
    почти всегда реплика. Это риск на таможне и при перепродаже.
[ ] Ограничения: батарейки, жидкости, порошки, ножи, лекарства,
    семена, продукты, радиопередатчики — уточнять заранее.
